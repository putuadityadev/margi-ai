# MARGI AI

**MARGI AI** (_Margi_ — Sanskrit/Balinese for a harmonious path) is a vibe-preserving crowd dispersion and micro-MSME rerouting engine built for the **Bali DigiFest 2026 — AI Web Innovation Challenge (AIWIC)**. Given a reference travel photo, origin hotspot, and arrival hour in WITA, a three-agent multimodal pipeline deconstructs the visual atmosphere, evaluates corridor bottlenecks across a three-tier crowd telemetry fallback chain, and pairs calm micro-radius (1–3 km) and regional alternatives across Bali's recipient regencies with nearby local MSMEs and curated cultural etiquette.
